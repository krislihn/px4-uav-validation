# 实验设计 Experiment Design

## 1. 目标

验证 SITL 仿真环境下自主飞行任务的可重复性，并给出可追溯的关键指标。

## 2. 环境与控制变量

- 固定：Ubuntu 22.04.5、PX4 v1.18.0-beta1-1012-gf16f99d4b5、Gazebo Sim 8.15.0、MAVSDK-Python 1.4.8
- 固定：每轮开始前做前置检查（rel_alt 约 0、in_air=False、armed=False）
- 固定：起飞高度 2.5 m；航点位于起点北向约 11.13 m
- 固定：遥测采样 1.000 s

## 3. 变量

| 类型 | 内容 |
| --- | --- |
| 自变量 | 判定阈值、稳定样本数、悬停窗口起点 |
| 因变量 | 悬停高度范围、水平漂移、航点水平/高度误差、PASS/FAIL |
| 控制变量 | 环境版本、起点状态、任务参数、采样频率 |

## 4. 基线

连续 3 轮完整测试套件，每轮 7 条用例，共 21 次判定。

## 5. 判定规则

- 连续 3 个样本满足阈值才判为通过，避免"刚跨过阈值"。
- 起飞后先稳定 5 s，再开始 20 s 的悬停窗口。
- 每个等待都有超时；超时记录实际值并判 FAIL。

## 6. 对照实验

已完成：

1. 把悬停漂移阈值改严 → 观察到 FAIL，验证套件能识别失败。
2. 上一轮中断后不清理状态 → 5/7，暴露"运行之间无状态隔离"，随后修复。

待做：

3. 风场 / 传感器噪声对照（需先确认当前 PX4 版本的插件与参数支持）。

## 7. 数据与记录

- 遥测：`logs/test_runs/*_telemetry.csv`
- 判定：`logs/test_runs/*_suite.csv`、`*.log`
- 汇总：`analysis/summary.csv`、`analysis/suite_summary.csv`

## 8. 已知限制

- 仅 SITL 仿真，未做 HITL 与真机。
- 航点水平误差稳定在 0.92–0.93 m，疑为飞控到位接受半径，未验证（known_issues 1.13）。
- 样本量较小（3 轮），结论只适用于当前配置。
